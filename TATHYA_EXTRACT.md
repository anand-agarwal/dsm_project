## 5. Env vars (new Vercel project + `.env.local`)

Same values as `frontend/.env.local` / `.env.example`. Never prefix Groq or Firecrawl with `VITE_`.

| Variable | Where | Purpose |
|---|---|---|
| `VITE_SUPABASE_URL` | Vite + Vercel | Same Supabase project as Bachpan |
| `VITE_SUPABASE_ANON_KEY` | Vite + Vercel | Read-only (RLS). Safe in the browser bundle |
| `GROQ_API_KEY` | Server only | `/api/chat` |
| `GROQ_MODEL` | Optional | Default model if the client does not send one |
| `GROQ_BASE_URL` | Optional | Default `https://api.groq.com/openai/v1` |
| `FIRECRAWL_API_KEY` | Server only | `web_search` (recommended) |

Do **not** put the Supabase **service role** key in the Tathya app.

On Vercel: Framework **Vite**, Root Directory **`.`** (if you flattened `frontend/`), env on Production **and** Preview. `GROQ_*` and `FIRECRAWL_*` must be server env, not `VITE_*`.
